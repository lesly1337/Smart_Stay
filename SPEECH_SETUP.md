# Голосовые сообщения: локальный dev-режим

Из корня проекта, тем же Python, который запускает бэкенд:

```powershell
py -m pip install -r requirements-speech.txt
$env:SMARTSTAY_LOCAL_SPEECH = "1"
py -m uvicorn main:app --reload --port 8000
```

Whisper small загружается при первом использовании (около 465 MiB), затем
переиспользуется в памяти сервера. `WHISPER_MODEL` позволяет задать другое имя
или локальный путь к модели. Версия pywhispercpp 1.3.3 выбрана для Python 3.9:
в 1.5.1 импорт падает на аннотации типов `bool | ...`.

В чате нажать микрофон, разрешить доступ, произнести «сделай теплее»,
«выключи свет» или «открой шторы», затем нажать квадрат остановки.
После распознавания текст появляется под аудиосообщением и поступает в
существующий обработчик текстовых команд приложения. Статус сохранения
настроек проверяется во вкладке «Управление».

Путь: MediaRecorder → браузерное преобразование в WAV mono 16 kHz →
POST `/api/speech/transcribe` → Whisper → `applyRoomCommand`.
Для передачи используется тело `audio/wav`, не multipart. Максимальная
длительность — две минуты; параллельное распознавание отклоняется с 429.
Временный файл удаляется после обработки, аудио и расшифровка не печатаются
в лог приложения. Запись остаётся в памяти браузера до перезагрузки.

Это адаптация STT-части предоставленного `speech_agent.py`.
Ollama/Qwen и модуль просьб Лёши пока не подключены: голос и текст используют
общий обработчик правил. Подключены все параметры карточек, но не произвольный
список действий в одной фразе. Примеры:

| Карточка | Команды |
| --- | --- |
| Свет | «включи свет», «яркость света 60 процентов», «приглуши свет», «тёплый свет», «холодный свет» |
| Климат | «температура 22 градуса», «сделай теплее», «сделай прохладнее» |
| Шторы | «открой шторы», «закрой шторы» |
| Звук | «включи шум дождя», «выключи звук», «громкость 30 процентов», «сделай потише» |
| Таймер звука | «поставь таймер звука на 15 минут», «отмени таймер звука» |
| Будильник | «поставь будильник на 07:30», «включи будильник» (если время задано), «выключи будильник», «будильник только светом», «будильник только звуком», «будильник свет и звук» |
| Не беспокоить | «включи не беспокоить», «выключи не беспокоить» |

Команда «команды» показывает подсказку в чате. Допустимые диапазоны:
яркость и громкость 0–100, температура 16–26 °C, время будильника 00:00–23:59,
таймер 1–1439 минут. Ошибочные значения не отправляются. Изменения проходят
через тот же `simulator.change`, что и карточки; таймер — через общий
`useSoundTimer`. Ответ помощника сообщает о запросе, подтверждение сохранения
остаётся в статусе соответствующей карточки.
Локальный Whisper включается только для разработки на ноутбуке.
По инструкции хакатона загруженные веса моделей в конкурсном решении запрещены.
На стенде start.sh принудительно отключает Whisper. Клиент проверяет доступность
до включения микрофона. На стенде используйте текстовый чат.
Для микрофона на телефоне нужен HTTPS; на компьютере подходит localhost.

Документация библиотеки: https://github.com/absadiki/pywhispercpp
