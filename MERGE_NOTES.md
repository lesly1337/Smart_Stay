# Объединение серверной сборки и текущего интерфейса

Источник: переданная папка `SmartStay-backend-simulator (1)`, 19.11.2026.
Рабочий проект: `SmartStay`. Копия прежних Python-файлов и фронтенда сохранена
рядом с проектом в `.update-review/before-backend-merge`.

Перенесены обработка кейса 2 `/run`, сценарии, предпочтения, обработчик просьб,
интерактивные гости и dev-сеансы, схемы и тесты. Для Windows/Python 3.9 заменены
аннотации `T | None`, чтение JSON явно использует UTF-8, зависимости FastAPI и
Uvicorn выбираются по версии Python. Добавлена tzdata для часовых поясов.

«Мой номер» теперь получает заезды и план с сервера. Работают выбор гостя,
пояснение предпочтений, применение сценария и просмотр виртуального периода.
Учёт истории вызывается отдельной кнопкой и требует доступного LLM-прокси.

Наши карточки, стили, анимации, голосовая запись, WAV-конвертация и Whisper small
сохранены. Известные команды всех карточек используют существующие проверенные
обработчики клиента и защищённые PATCH-запросы; остальные просьбы идут в
серверный `/api/room/command` с уникальным command_id. После ответа состояние
перечитывается. Для произвольных просьб серверу нужны LLM_BASE_URL,
LLM_API_KEY и LLM_MODEL; при отказе сервера чат показывает ошибку.

Клиент открывает отдельный dev-прогон автоматически через `/api/room/session`.
Командный токен берётся из окружения либо существующего simulator.local.json /
HACK_TEAM_TOKEN_FILE. Секреты не передаются в браузер. Вручную заданные старые
session_id/run_id больше не определяют активный UI-сеанс. При истечении есть
кнопка создания нового сеанса. Все записи передают X-Room-Session.

Проверено: 63 Python-теста, 16 Node-тестов, production-сборка; Chrome 390×844:
5 гостей, 3 периода и карточки управления без горизонтального переполнения.
На реальном dev-сеансе план первого гостя применён: 13 шагов, статус applied;
настройки прочитаны обратно. Полный конкурсный `/run` и новые LLM-вызовы
в ходе этого объединения не запускались.

Запуск из корня: `py -m uvicorn main:app --reload --port 8000`.
Фронтенд из `FrontEnd/my-app`: `npm run dev`.
Тесты: `py -m unittest discover -s tests -p 'test_*.py'`,
`node --test tests/*.test.mjs`. Для тестового HTTP-клиента нужен `httpx`.
